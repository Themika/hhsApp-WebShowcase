# HHS Stroke Protocol Engine

A streamlined web application designed to manage and execute stroke protocol workflows directly in your browser.

## Features
- **Dynamic Protocol Management:** Easily add, edit, and organize protocol steps via an intuitive interface.
- **User-Friendly Navigation:** Clean, card-based UI for quick access to clinical steps.
- **Local Data Persistence:** Your protocol configurations are automatically saved to your browser, ensuring your work remains available between sessions.
- **Data Portability:** Easily export your protocols as a text file and import them back at any time to back up or share your configurations.

## Usage
- **Navigation:** Use the dashboard to view and interact with your clinical protocols.
- **Adding/Editing Steps:** Use the "Add Step" or "Edit" buttons to modify your protocol criteria.
- **Importing Data:** Click the **Import TXT** button to load a previously saved protocol configuration.
- **Exporting Data:** Click the **Export TXT** button to download your current protocol configuration to your local device.

## Data Privacy & Hosting
This application is a static web tool hosted on GitHub Pages. 
- **Privacy:** All data is processed and stored locally within your web browser. 
- **Security:** No data is transmitted to an external server or backend database.

## Disclaimer
**Note:** This application is a tool for organizing protocols and is intended for informational/procedural support. Always ensure protocol updates are verified against current medical standards and institutional guidelines before clinical application.
